<role>
You are a Node.js HTTP contract test engineer. Create one real in-memory WHEP
session through the route, then verify explicit teardown and unsupported-method
responses without testing lifecycle timers owned by T40.
</role>

<context>
Clients end sessions with `DELETE /whep/watch/:sessionId`. The route closes the
room session when the room exists and otherwise removes an orphaned global
entry. A second DELETE returns 404. Trickle ICE is intentionally unsupported;
every PATCH returns stable 501. No direct test covers either method.

Use the opaque id from the successful POST Location. Do not invent a
client-visible session URL by reaching into registry internals.
</context>

Do not touch: `lib/whepRoutes.js` — assertion-only task

</files>

<task>
Pin successful, repeated, missing-room, and unknown-session DELETE behavior plus
the explicit 501 PATCH contract. Assert headers and cleanup, not status alone.
</task>

<steps>
- Copy the minimal video-only POST harness. Track concrete close counts and
  extract the 32-hex id from the 201 Location.
- Existing room DELETE: assert 200 `{ ok: true }`, both map removals, viewer zero,
  and one close each. Repeat and assert 404
  `{ error: 'WHEP session not found' }` with unchanged counts.
- Unknown session: DELETE a different 32-hex id and assert the same 404 without
  touching a live fixture.
- Missing-room orphan: after POST, remove room from `sessionRegistry.rooms`
  without closing its WHEP session; DELETE returns 200 and removes global entry.
  In `finally`, restore the room to the map and call normal destruction so the
  room-local orphan resources close.
- PATCH: send `application/trickle-ice-sdpfrag` and
  `Origin: https://allowed.example`; configure exact allowed-origin predicate.
  Assert 501 `{ error: 'Trickle ICE not implemented' }`, reflected origin,
  `Vary: Origin`, allowed methods/headers, and exposed Location. A live session
  remains untouched.
- Restore config/maps/sessions/resources/servers in `finally`; use unique rooms
  and IPs.
</steps>

<constraints>
- Scope: create only `tests/whepRoutesMethods.test.js`.
- Exercise DELETE over HTTP; do not call exported `closeWhepSession()` as action.
- Orphan setup may manipulate public `sessionRegistry.rooms`, but must restore it.
- Assert JSON, CORS, both maps, viewer count, and exact close counts.
- Do not test timer advancement or lifecycle signals.
- Declare mutating cases `{ concurrency: false }`.
- Do not implement trickle ICE or edit production source.
</constraints>

- Fabricated orphan resources are explicitly cleaned.
- Final room/global registry sizes equal baseline.
- `git diff --name-only` lists only `tests/whepRoutesMethods.test.js`.
</acceptance_criteria>
