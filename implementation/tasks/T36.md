  fake reaches exported `createMediasoupWorker()` without a subprocess.
- The fake needs `createRouter()` and `createWebRtcServer()` methods; the latter
  receives exact `{ listenInfos }`.
- Module-level worker/router/server state requires deleting only the exact
  `lib/mediasoup.js` require-cache entry between cases.
</context>

<task>
Assert exact `listenInfos` for loopback, LAN, and distinct-public configs. Also
prove a rejected shared-server creation resolves normally and the next transport
uses existing per-transport fallback.
</task>

<steps>
- Build a helper saving the five relevant config values and original
  `mediasoup.createWorker`, deleting only the exact mediasoup-module cache entry,
  and installing an EventEmitter fake worker. Restore all three in `finally`.
- Loopback: assert UDP then TCP on `RTC_MIN_PORT`, both bind `127.0.0.1`, both
  `announcedAddress: undefined`.
- LAN only: bind `0.0.0.0`; assert UDP then TCP on the base port announcing LAN.
- Public distinct from LAN: assert public UDP/TCP first on base port + 1, then
  LAN UDP/TCP on the base port.
- Public equals LAN: assert only the two LAN entries.
- Creation failure: reject fake `createWebRtcServer()`, assert worker creation
  still resolves, then call the same fresh module's transport function and
  assert exact fallback `listenIps` with no `webRtcServer` property.
</steps>
