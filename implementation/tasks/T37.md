<role>

<context>
WHEP is an optional public HTTP viewer surface. Pure SDP helpers have broad unit
coverage, but `tests/whepRoutes.test.js` contains only one concurrent capacity
test. It does not protect CORS reflection, disabled/missing-room responses,
no-producer response, or the documented bearer-passphrase contract.

`createWhepRouter()` accepts `isAllowedOrigin`, `getClientIp`, and
`createWebRtcTransport` options. Use those boundaries; no source seam or package
is needed. Admission checks availability, rate, room, producer, passphrase, and
capacity before parsing SDP or creating a transport.

For successful-password proof, set `MAX_VIEWERS_PER_ROOM=0`. A correct bearer
passes authentication and reaches the next gate (`503 Room is full`); missing
or wrong credentials return 401 first, without media allocation.
</context>

<task>
Add HTTP-level tests for trusted-origin CORS, feature availability, room and
producer lookup, and bearer passphrase admission. Every rejection must prove the
injected media transport factory was not called.
</task>

<steps>
- Copy the minimal listener and SDP fixture style. Mount at `/whep`, listen on
  `127.0.0.1`, and use an ephemeral port.
- CORS preflight: accept only `https://allowed.example`. Assert allowed OPTIONS
  returns 204, reflects exactly, sets `Vary: Origin`, advertises
  POST/DELETE/PATCH/OPTIONS and Content-Type/Authorization, while denied origin
  receives no `Access-Control-Allow-Origin`.
- With WHEP disabled, POST a valid offer and assert 404
  `{ error: 'WHEP is not enabled' }` and no allocation.
- Enable WHEP; assert missing room returns 404 `{ error: 'Room not found' }`.
- Create a room without a video producer; assert 409
  `{ error: 'No active video producer in this room' }`.
- Create a room with passphrase `open sesame` and fake video producer. Set room
  limit zero, global/rate limits high. Missing and wrong Bearer headers return
  401 with `WWW-Authenticate: Bearer realm="Nextra room"` and documented error;
  correct `Authorization: Bearer open sesame` reaches 503 `Room is full`.
- Restore config, destroy rooms, and close servers in `finally`. Use unique IPs.
</steps>
