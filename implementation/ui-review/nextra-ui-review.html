The share link is the product

Once you are live there is one job left: get the link to people.

Round 3Option A is gone. The invite card now handles several links: the room code first, then one row per link with a short label and its own copy button. The best one to share is marked.

How the invite card handles links

  • The room code comes first, always.
  • One row per link, each with a short plain label and a copy button.
  • The best link to share is marked and gets the only bright button: the public link if there is one, otherwise the local link.
  • Long links are shortened in the middle, so the start and the room code stay readable. Copy always copies the whole link.
  • The card is always exactly as tall as the picture. If more links ever appear, the list scrolls inside the card.

Limits of this review

What I could not capture

  • A live OBS stream. It needs OBS Studio, and the OBS link was switched off on my test server. The OBS setup screen and its error message above are real.
  • The backup ("relay") way of watching, and its "Switch to Relay Mode" and "Try WebRTC" buttons.
  • The public link and the external player link. Both were off on my test server, so the host card shows only a local link.
  • The viewer's "Play/Pause Host Media" button. My test server had it switched off, which is why that option looks greyed out in the host screenshots.
  • Safari, Firefox and Windows. Every shot is Chromium on Linux, where Inter happens to be installed.
