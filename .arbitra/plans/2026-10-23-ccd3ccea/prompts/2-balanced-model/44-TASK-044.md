<goal>
Make scripts/opensource-preflight.js reject tracked .env files at any depth. Enumerate tracked files with NUL-delimited output, and fail closed on tracked regular files it cannot read.

This matters because it fixes:
- Open-source preflight only blocks root-level .env files; tracked .env files in subdirectories pass the gate (medium)
  forbiddenTracked lists only root-relative names. The .env path regex is anchored at the start with no directory prefix, unlike the certs/ and binary rules, which accept '(?:^|/)'. As a result, poc-mediasoup/.env, server/.env.production or config/.env.local are neither in the set nor matched. The content scan only recognises a few vendor token formats. Generic secrets in such files therefore pass, and the gate prints OK. Examples: passwords, tunnel tokens, METRICS_TOKEN values, TURN credentials.
- Git-quoted filenames bypass preflight content scanning (medium)
  <quotes> const output = execSync('git ls-files', { cwd: root, stdio: ['ignore', 'pipe', 'ignore'] }).toString('utf-8'); return false; if (!isTextFile(absPath)) continue; </quotes> Without -z, git ls-files quotes and escapes unusual filenames, including non-ASCII names under Git's default core.quotePath setting. The script treats that display representation as a literal filesystem path. Reading it fails, isTextFile returns false, and the tracked file is silently skipped instead of scanned for secrets.
</goal>
