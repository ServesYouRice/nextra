<goal>
Stop poll ticks from aborting slow metrics requests, and make slow or failed requests visible instead of silently cancelled.

This matters because it fixes:
- Status polling can continually abort slow metrics requests (medium)
  <quotes> src/StatusView.jsx:7 const REFRESH_INTERVAL_MS = 5000; src/StatusView.jsx:43 abortRef.current?.abort(); src/StatusView.jsx:76: void fetchMetrics(); src/StatusView.jsx:69 if (err?.name === 'AbortError') return; </quotes> Every refresh aborts the preceding request, and the poll callback discards its promise. Consequently, even a poller that normally awaits asynchronous work cannot observe that this request remains pending. If successive refresh ticks occur every five seconds, requests taking longer than that are repeatedly cancelled without an error being displayed.
</goal>
