<goal>
Stop the CSP from telling browsers to upgrade same-origin requests to HTTPS when Nextra serves plain HTTP.

This matters because it fixes:
- HTTP-only serving can still instruct browsers to upgrade resources to HTTPS (medium)
  <quotes> upgradeInsecureRequests: config.ALLOW_INSECURE_TRUSTED_LAN_RELAY ? null : [], if (config.LOCAL_HTTPS) { const { cert, key } = await getOrCreateCert(); appServer = https.createServer({ cert, key }, app); } else { appServer = http.createServer(app); } </quotes> The upgrade-insecure-requests directive is controlled by relay policy rather than the effective serving scheme. With LOCAL_HTTPS disabled and insecure LAN relay disabled, the listener is HTTP-only but the CSP still requests HTTPS upgrades. Browsers applying this upgrade to localhost, notably Safari, can request application resources over TLS on a plaintext port.
</goal>
