Synchronous URL revocation in downloadDiagnosticBundle aborts file downloads (high)

In downloadDiagnosticBundle, urlApi.revokeObjectURL(objectUrl) is executed synchronously in the finally block immediately following link.click(). Because modern browser download initiation triggered by synthesized anchor clicks is asynchronous, revoking the blob URL in the same event-loop tick tears down the blob URL before the browser's download manager can resolve and retrieve the blob content.
