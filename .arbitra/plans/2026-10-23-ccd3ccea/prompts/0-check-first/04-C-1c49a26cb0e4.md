Missing host authorization in connect-transport allows viewers to hijack or break host send transport (high)

In socket handler connect-transport, the server checks if transportId matches room.hostTransport.id before checking viewer transports. However, findRoomBySocket(socket.id) returns the room for both hosts and viewers, and the handler never checks whether socket.id matches room.hostSocketId before connecting room.hostTransport. A viewer in the room who knows or guesses the host's transport ID can invoke connect-transport with arbitrary DTLS parameters against the host send transport.
