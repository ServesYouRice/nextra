What changed in lib/whipRoutes.js:

Used by cancelPendingStart (step 3), the post-connect check, the POST catch path and the 400 for a missing DTLS fingerprint.
- Per-start closures: isCurrentSession() (room.whipGeneration and room.whipTransport still this start's), isCurrentStart() (also not cancelled), isCurrentConnected() (also a local dtlsState of 'connected'), commitProducer() and teardownGeneration(reason).

The redundant `room.whipTransport = transport` after connect is gone (the check guarantees it).
- Producers: `const producer = await transport.produce(...)`, then commitProducer() assigns the room field and calls ownWhip only while isCurrentConnected(); otherwise only that producer is closed. whipConnected is set only after a final isCurrentConnected() check.
- The connected branch's catch calls teardownGeneration('producer creation failed') when producers were not all made (stopFallbackRelay, closeWhipSession, fallbackAvailable = false, emitHostMetrics). An error thrown after going live is only logged, as before (it does not tear down a working session).
- The failed/closed branch and the grace-timer callback act only for the current session; the grace callback clears room.whipGraceTimer only if it is its own timer and expires through teardownGeneration('grace period expired').
