TASK-062 (lane client): sanitizeDiagnosticText in src/lib/diagnosticBundle.mjs now covers formats (a) to (e) of the issue. Only that file and tests/diagnosticBundle.test.js changed. Verify commands, lint, typecheck and npm test (590 tests) pass.

What the rules do now, in order: any `scheme://` link is `[redacted-url]` (rtmp, rtsp, srt, file, ftp and so on), then stun/turn; `Authorization` takes its whole value (scheme, credential and Digest parameters, or a quoted value), `Bearer x` as before; secret keys (token, secret, password, passwd, passphrase, credential(s), api key, bearer, room code, with any prefix such as hostToken or access_token) accept quotes around the key and the value, and a quoted key keeps its shape (`{"token":"[redacted]"}`); a room code is redacted after the word room/room code/room id (any case, code must be upper case), after `#watch/`, `/whep/watch/`, `/whip/broadcast/` (whatever segment follows, since it is a code or session id) and after `/whip/` and `/whep/`; IPv4 (with port), bracketed and bare IPv6 (with port), `localhost:port` and dotted `name:port` are `[redacted-url]`; hex of 32+ characters in either case, the old 48+ character token rule, and base64 with +, / or = (32+ characters, or 20+ when padded with `=`, with upper case, lower case and a digit) are `[redacted-value]`.

Choices the prompt left open:
- Room-code alphabet: lib/rooms.js uses A-HJ-NP-Z2-9 (no I, O, 0, 1), but the issue's own examples use `AB12CD`. Redaction accepts any upper-case letter or digit (6 characters, optional middle hyphen as the host UI shows it), so a hand-typed code is covered. A test reads CHARS and CODE_LENGTH from lib/rooms.js and checks every character of the server alphabet is redacted in all four contexts.
- No lookbehind is used: the module ships to the browser and the vite default target includes Safari 16.0 to 16.3, which reject it.
- Markers: addresses and host:port values use the existing `[redacted-url]`; room codes and key values use `[redacted]`; long values use `[redacted-value]`.
- Not redacted on purpose: a bare host name without a port (`relay.example.com`), single-label `name:port`, and 32 to 47 character alphanumeric strings without +, / or = (they cannot be told from identifiers). `HostView.jsx:538`-style stack-trace locations are kept by a short list of file endings.
